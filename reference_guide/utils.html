Utils

class tools.config_manager.ConfigManager

Bases: object

Manages configuration settings loaded from the JSON config file and optionally overridden by command-line arguments.

This class ensures that required parameters are present and valid, while applying defaults for optional settings.

CONFIG_HELP_MSG = 'Path to the JSON configuration file (required).'
HELP_DESCRIPTION = 'Override JSON config fields with command line arguments.'
OPTIONAL_PARAMS = {'cgcnn_batch_size': (256, 'Batch size for CGCNN.'), 'cpu_account': ('', 'The cpu account name on the current machine (forwarded to the workload manager).'), 'formation_energy_threshold': (-0.2, 'A formation energy threshold used for selecting the structures, after the CGCNN prediction.'), 'gpu_account': ('', 'The gpu account name on the current machine (forwarded to the workload manager).'), 'num_workers': (128, 'Number of threads used for generating, predicting and selecting the structures.'), 'output_level': ('INFO', 'Logging level: DEBUG, INFO, WARNING, ERROR, CRITICAL'), 'vasp_force_conv': (100, 'VASP force convergence threshold.'), 'vasp_nnodes': (1, 'Number of nodes used for VASP calculations.'), 'vasp_nstructures': (-1, 'Number of structures to be processed with VASP.
